## Projeto em destaque

### agIA — Gestão Inteligente de Agenda

Sistema web criado para a Autoescola KM que centraliza alunos, aulas, instrutores, veículos e unidades em um só lugar.

- Idealizei o projeto a partir de necessidades que identifiquei trabalhando na operação da autoescola
- Levantei os requisitos e defini as regras de negócio: agendamentos, cancelamentos, reposições e permissões por perfil (aluno, instrutor e administração)
- Desenvolvo o front-end em HTML, CSS e JavaScript, com layout responsivo
- Apoio o desenvolvimento do back-end em C#/.NET e do banco de dados SQL Server

### [GymPlanner](https://github.com/teteusalvescorrea-hub/GymPlanner)

Aplicação web para organizar a rotina fitness: calculadoras de IMC, TMB, calorias, água e macronutrientes, gerador de treinos, sugestões de refeições e checklist semanal, com dados salvos no navegador (LocalStorage) e layout responsivo. Feito em HTML, CSS e JavaScript puro.
